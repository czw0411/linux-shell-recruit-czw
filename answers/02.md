# Task 02 Answer

1. 执行 chmod +x tools/recruit-info 为脚本添加执行权限，即可用 ./tools/recruit-info 运行。

2. ./tools/recruit-info 能运行，是因为 ./ 明确告诉 Shell 在当前目录中查找文件；而直接输入 recruit-info 时，Shell 只会按环境变量 PATH 中列出的目录逐个查找，当前目录通常不在 PATH 中，因此找不到。

3. Shell 输入 ls 时，会依序搜索 PATH 里的目录（如 /usr/bin），找到可执行的 /usr/bin/ls 并运行，可用 command -v ls 查看其实际路径。

4. 本次会话执行 export PATH="$PATH:$HOME/linux-shell-recruit-czw/tools"，之后直接输入 recruit-info 即可运行；此修改只对当前会话生效，不改 .bashrc、不移动文件。
